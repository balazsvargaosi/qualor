# Fonts of the compliance report PDF

Noto Sans Regular and Bold, embedded (as subsets) in the PDF the compliance report renders (4E-1
§2.5). They cover Latin, Greek and Cyrillic. The files are byte-for-byte copies of the unhinted
static TTFs of the official Noto release; PDF viewers ignore TrueType hinting, so the unhinted
files keep the image and every PDF smaller with the same glyphs.

- **Release:** Noto Sans v2.015 (`notofonts/latin-greek-cyrillic`, tag `NotoSans-v2.015`,
  2024-11-20)
